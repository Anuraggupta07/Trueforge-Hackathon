Warden

Cloud cleanup that proves it's safe first.

Warden finds wasted cloud spend, refuses to touch anything risky, and deletes nothing until an independent Watchdog has checked it and a human has clicked Allow. Every change can be undone.

The problem

29%

of cloud spend is wasted. Flexera, State of the Cloud 2026 ↗

Finding waste is easy. Cleaning it up is where teams get stuck.

  • Fear

    Deleting the wrong thing causes outages. Atlassian's cleanup script got the wrong IDs and deleted 883 customer sites in 2022.

    Warden: reversible by default, with a Watchdog check and human approval on every change.

  • It comes back

    The same waste returns next month. A launch template quietly keeps a disk every time a server dies.

    Warden: finds the leak and gives you the one-line fix.

  • Paperwork

    Every change needs evidence and a rollback plan, so cleanup tickets wait for weeks.

    Warden: receipts, a tamper-evident log and a generated change record.

The system

Warden is our code. TrueForge runs the agent around it.

You chat in TrueForge. Its AI can reach your cloud only through Warden's tools, and every action stops at an Allow / Deny gate. Press Next to follow one cleanup through the system.

Warden: 19 MCP tools, 491 tests · TrueForge: chat, approvals, dashboards · Daytona: sandboxed proof code

    What Warden does

    Reversible first. Permanent last, one at a time.

    It findsWarden's safe actionCan you undo it?Approval
    Unused diskEBS volume Back it up, wait for the backup to finish, then delete Yes, one click Per batch, max 5
    Orphaned snapshotEBS snapshot Move it to the AWS Recycle Bin Yes, for 7 days Per batch, max 5
    Idle serverEC2 instance Stop it. Never terminate. Yes, start it again Per batch, max 5
    Unused public IPElastic IP Quarantine it with a tag (the IP keeps working). Release only after the window. During the window Release is permanent Release: one IP per approval

    The rule is enforced in code, not only in the AI's instructions. Reversible actions are approved per batch. Anything permanent is approved one item at a time, after a visible waiting window.

    No new waste. Warden's own backups expire after 7 days.

    Safety

    Nine locks between the AI and your cloud account.

    Plan lock

    The AI can act only on IDs the scanner certified, so a wrong-ID mistake like Atlassian's can't happen.

    Watchdog sign-off

    A one-time permission slip, cryptographically signed (HMAC), that expires. No slip, no action.

    Human approval

    TrueForge pauses on all 10 action tools until you click Allow.

    Re-check before acting

    If someone attached the disk after you clicked Allow, Warden skips it.

    Two locks on production

    Production-tagged items are refused in Warden's code, and blocked again by an AWS permission policy (IAM).

    AWS dry run

    AWS confirms each call would succeed before Warden proposes it.

    Freeze switch

    One setting blocks every change, for example during a quarter-end freeze. WARDEN_FREEZE=true

    Scope guard

    Warden only touches resources with a chosen tag. warden:demo=true

    Tamper-evident log

    Every scan, sign-off and action is hash-chained. Edits, deletions and truncation are detected.

    Neverterminates serverstouches encryption keysdeletes S3 buckets

    Receipts and the ledger

    Ask what happened. Get an answer you can check.

    Every change leaves a receipt with its undo, and every scan, sign-off and action lands in a hash-chained ledger. Warden answers from the record, without rescanning.

    Agents That Act

    What the brief asked for, and how Warden does it.

    Reach real systemsA custom MCP server makes real AWS API calls (EC2, CloudWatch, CloudTrail, Recycle Bin, Route 53, ELBv2) under a least-privilege IAM policy.
    Execute safelyProof scripts and the change record run as code in the Daytona sandbox. Every change is plan-locked, Watchdog-signed, human-approved and dry-run checked.
    Recover from failureA receipt for every call, one-click undo, a live rollback countdown, and “check the receipt” after a timeout.
    Know when to stop and askReview tiers, one-item approvals for permanent steps, the quarantine window, the freeze switch, and Watchdog blocks that can't be bypassed.
    Keep contextThe locked plan, the receipts and the ledger. “What happened to X?” is answered from the log.
